# Contributing to Earth Elements Business Setup Case Study

Thank you for your interest in improving this case study repository.

## Ways to Contribute

- **Documentation improvements**: Fix typos, clarify steps, add missing context.
- **Asset improvements**: Suggest better screenshots, optimized images, or alternative creatives (keep branding consistent).
- **FAQ expansions**: Add real questions clients ask about Google Business Profile, Google Ads, or social linking.
- **Related examples**: Propose similar case studies (open an issue first).
- **Translations**: Local language (Gujarati / Hindi) versions of key sections are welcome.

## How to Contribute

1. Open an issue describing the change.
2. Fork the repository.
3. Create a feature branch (`git checkout -b docs/improve-faq`).
4. Make focused commits.
5. Open a Pull Request with a clear description.

## Smallest Useful Contribution

Fix a single broken link, improve one sentence in the README, or add one missing FAQ answer.
