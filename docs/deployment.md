# Deployment & Publication Notes

This repository is a static case study. No build step or server is required.

## Viewing Locally

```bash
git clone https://github.com/SNTL84/earth-elements-business-setup.git
cd earth-elements-business-setup
# Open README.md in any Markdown viewer or on GitHub
```

## GitHub Pages (optional)

If you want a simple HTML landing page later:

1. Add an `index.html` that links to the live Google / Instagram / Facebook profiles.
2. Enable GitHub Pages on the `main` branch / root or `/docs` folder.

## Assets

All brand images live under `/assets` and are referenced relatively so they work both on GitHub and in local clones.
