# Security Policy

## Supported Versions

This is a documentation and case-study repository. There is no runtime application code that processes user data.

| Version | Supported |
| ------- | --------- |
| main    | ✅        |

## Reporting a Vulnerability

If you discover a security concern related to:

- Exposed credentials or secrets in any committed file
- Misleading claims that could harm users
- Links that lead to phishing or malicious content

Please report privately:

- WhatsApp: [wa.me/919727413309](https://wa.me/919727413309)
- Or open a private security advisory on GitHub if available

Do **not** open a public issue for sensitive findings.

## Secrets Handling

- No API keys, passwords, or client credentials are stored in this repository.
- All client-facing links (Google Business, Instagram, Facebook) are public business profiles.
- Screenshots and assets contain only publicly visible brand information.

## Known Risks

- External links (Google share, Instagram, Facebook) are controlled by third parties and may change.
- Users should verify any business profile before contacting the listed business.
